El lenguaje SQL (Structured Query Language) consiste en:

- **DDL**: Data Definition Language. Permite crear y manipular la estructura de la BD.

- **DML**: Data Manipulation Language. Permite recuperar, almacenar, modificar, eliminar, insertar y actualizar datos de una BD.

- **DCL**: Data Control Language. Permite crear role, permisos e integridad referencial, así como el control de acceso.
